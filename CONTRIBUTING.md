# Contributing

- One link per line: `- [Name](url) - Short description.` (end with a period).
- Add to the right section, keep alphabetical order when possible.
- Tool must be maintained or clearly marked `(archived)`.
- Run `python3 tools/check_links.py` before opening a PR.
- Behavioral focus: tools that infer patterns/habits/attribution, not just raw lookups.
- No tools whose primary purpose is harassment, stalking or illegal access.

## Not accepted (examples)

- Tools whose main features are sockpuppet generation, mass account creation or detection evasion.
- Pipelines that build target profiles to craft tailored phishing (write-ups of defensive research are fine).
